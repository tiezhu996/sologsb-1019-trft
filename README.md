# 访谈文本主题编码工具

`sologsb-1019` 是一个面向质性研究者的本地优先主题编码工作台，使用 SolidJS、TypeScript 和 SUID 从零构建。

## 功能

- **研究项目工作区与共享编码方案库分离**：每个项目独立保存本项目的转写、两位编码者的判断、人员姓名和操作审计；共享方案库只保存可复用的主题定义。
- **新项目复制方案快照**：建项目时把所选方案完整复制为项目快照（记录方案修订号）。之后方案库改版只影响之后新建的项目，**不会改动已开始的项目**；项目内的增删改也不影响其他项目。
- **本地调整按差异回写**：项目内沉淀的主题调整可在回写对话框中先查看“新增 / 修改 / 移除”差异列表，勾选确认后才写回共享方案；新增子主题依赖的新增父主题自动标记为必选，移除父主题时子主题提升为顶层，不产生悬空层级。
- **检查点与失败重试**：创建项目、回写方案、迁移旧数据等多记录操作先写检查点（独立存储区，同时备份到 localStorage）。写入失败后可从横幅“从检查点重试”，依靠预分配 ID 与整记录覆盖保证幂等——**不会多出一套主题或一个项目**；也可放弃该操作（不落库任何主题）。
- **旧数据自动迁移**：旧版单一工作区数据首次打开时迁移为“默认研究项目”，原转写、双编码者判断、人员姓名、审计记录完整保留；原主题同时存入共享方案库。
- 导入带时间码或普通段落形式的访谈转写，自动切分片段。
- 创建任意层级主题树，维护操作定义、备忘录和典型示例（项目内）。
- 为每个片段分别记录两位编码者的主题判断，并高亮分歧。
- 批量选择片段后重新编码，支持主题合并和按片段拆分。
- 从主题引用快速回到原文，并保留主题级与片段级研究记录。
- 完整撤销重做、操作审计、JSON 完整备份和 CSV 编码结果导出。
- J/K、数字键、Alt+A/Alt+B、搜索与通用撤销快捷键。
- 使用 IndexedDB 和 localStorage 双写保存；刷新或断网后继续工作。
- 使用 BroadcastChannel 监测其他标签页修订（按项目 / 方案库 / 登记簿分别提示），发生并发写入时显示冲突，不会静默覆盖。

## 数据结构

IndexedDB（v2，两个 object store）中的记录：

| 键 | 内容 |
| --- | --- |
| `library` | 共享编码方案库（多个可复用方案，各自带修订号） |
| `registry` | 项目登记簿：项目清单与当前打开的项目 |
| `project:<id>` | 研究项目工作区：转写、片段判断、人员、审计与方案快照（含回写差异基线） |
| 检查点区 `pending` | 未完成的多记录操作，用于失败后幂等重试 |

旧版 v1 的 `current` 快照与 `sologsb-1019-state-v1` localStorage 在迁移成功后删除。

## 技术栈

- SolidJS 1.9
- TypeScript 5.9
- SUID Material `@suid/material`
- Vite 7
- IndexedDB / localStorage / BroadcastChannel

## 开发

```bash
npm install
npm run dev
```

开发服务器使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## 逻辑验证（无需浏览器）

`test/e2e.cjs` 在 jsdom + fake-indexeddb 下直接驱动 store，覆盖：快照隔离、库改版不影响在建项目、新项目复制最新快照、回写差异与幂等、检查点失败重试不产生重复项目、旧数据迁移不丢判断/人员/审计、刷新后不重复迁移：

```bash
node -e "require('esbuild').build({entryPoints:['test/entry.ts'],bundle:true,format:'cjs',platform:'node',outfile:'dist-test/store-bundle.cjs',external:['solid-js','solid-js/store']})"
node test/e2e.cjs
```

## Docker

```bash
docker build -t sologsb-1019 .
docker run --rm -p 10019:80 sologsb-1019
```

容器内由 nginx 监听 `80`，宿主端口 `10019` 仅由根项目端口表或部署命令映射。

## 数据说明

数据保存在浏览器本机，不会发送到远端。多个标签页同时编辑时后写入者不会自动覆盖先写入者；界面会要求研究者明确选择“载入其他标签页版本”或“保留本页并建立新修订”。
